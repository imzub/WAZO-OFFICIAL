## Validation

- All eight files are landscape PNG images at `1920 x 1080`, well above the recommended `1366 x 768` minimum and below the `50 MB` per-file limit shown in Partner Center.
- Every image was visually inspected for layout, clipping, meaningful feature coverage, and accidental machine-path disclosure.
- The set was recaptured with the v1.1.4 `r2-redesign` Organized W mark so the Store listing matches the AppX, installer, Android resources, and in-app branding.
- The capture used WAZO `1.1.4` with a fresh isolated profile, the bundled anonymous Demo Family seed, and one capture-only SIP example. No installed user data or repository seed data was modified.
- Privacy Mode was intentionally off because all displayed records are test data.
- These are Store-listing media files only. They do not alter the v1.1.4 application, AppX, installer, or version metadata.

`captions.json` contains the same captions in machine-readable form. `screenshots-manifest.json` records dimensions, byte sizes, SHA-256 hashes, and validation provenance for the exact PNG files.
