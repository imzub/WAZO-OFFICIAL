Private by design

Your data stays on your machine.

WAZO is designed around local JSON files for portfolio data, settings, activity logs, and diagnostic events. Backups are user-controlled, and financial data is not sent to a developer cloud.

Questions

Quick answers for visitors.

Is WAZO only for zakat users?

No. WAZO is a general personal wealth organizer. The zakat module is optional and can be enabled only when needed.

Does WAZO need internet?

The app is built offline-first. Core data, settings, reports, and backups are stored locally.

Where is data stored?

WAZO uses local JSON files for portfolio data, settings, activity logs, and diagnostic events.
