Questions

Quick help for new users.

How do I add a family profile?

Open Settings, choose Member Setup, then use Add / Edit Family to create a profile. New installs show a highlighted shortcut until this setup is complete.

How do I add members?

Go to Settings > Member Setup. Add members under Member Register. Assets should be linked to the member who owns them.

How do I add an asset?

Open Assets, select the financial year, then fill Add / Edit Asset. Choose the owner, asset type, purchase details, current value, and save.

How do I set allocation targets?

On the Assets page, use Allocation Targets to set desired category percentages. Portfolio uses those targets to show required rebalancing.

How do I change the theme?

Open Settings > Themes, choose a theme, font size, and control size, then save. Theme choices help adapt the app for personal preference.

How do I back up data?

Open Settings > Storage, choose a backup folder, then run Backup All JSON Files. Automatic backup can be configured by frequency.

How do I generate reports or PDFs?

Open Reports, choose the report type, financial year, and scope, then export as PDF, HTML, Excel-compatible file, CSV, or JSON.

Is WAZO only for zakat users?

No. WAZO is a general personal wealth organizer. Zakat is optional and can be hidden if not needed.

Does WAZO need internet?

No for core workflows. WAZO is offline-first and stores its main data locally as JSON.

Where is data stored?

WAZO stores portfolio data, settings, activity logs, and event logs in local JSON files in the app data folder.
