# WAZO v1.1.9 - Testing build

WAZO v1.1.9 is an optional Windows x64 deep-audit testing build. WAZO v1.1.7 remains the stable public release and is unchanged.

Testing notes:

- Portfolio Refresh now serializes repeated clicks, reports already-current state clearly, and exposes bounded recovery controls for slow renderer operations.
- Refresh preserves protected stores, historical snapshots, append-only confirmed investment facts, and open editor input.
- Settings is searchable, essentials-first, section-compatible, and no longer jumps the whole window when changing sections.
- Date-only XIRR, simple CAGR, and Zakat intervals are timezone/DST-safe; lower-case reporting-currency migration records are normalized; financial-year controls stay compact at normal widths.
- The reproducible breadth gate passed 100,000 deterministic scenario probes and 460,000 assertions across financial-year policies, dates, time zones, locales, currencies, label styles, and edge values. This is parameterized coverage, not a claim of 100,000 human sessions.
