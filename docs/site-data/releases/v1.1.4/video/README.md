# WAZO v1.1.4 Product Tour

Public, browser-ready assets for the English narrated WAZO product tour.

- `WAZO-Narrated-Explainer-v1.1.4.mp4`: web/review encode used by the website.
- `WAZO-Narrated-Explainer-v1.1.4-Poster.png`: 1920 × 1080 poster.
- `WAZO-Narrated-Explainer-v1.1.4-English.vtt`: browser caption track.
- `WAZO-Narrated-Explainer-v1.1.4-English.srt`: downloadable subtitle sidecar.
- `WAZO-Narrated-Explainer-v1.1.4-Transcript.md`: readable English transcript.
- `video.json`: sizes, hashes, timing, source, and production-handoff pointers.

The video uses an isolated anonymous demo profile. It demonstrates v1.1.4 core workflows and must not be used as visual evidence of the protected-storage behavior added in v1.1.5.

The complete editable production workspace is retained outside the GitHub Pages source under `project-data/releases/v1.1.4/promo/narrated/`.
