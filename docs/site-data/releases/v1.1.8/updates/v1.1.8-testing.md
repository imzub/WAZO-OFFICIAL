# WAZO v1.1.8 — Testing build

WAZO v1.1.8 is available as an optional Windows x64 testing build. WAZO v1.1.7 remains the stable public release and is unchanged.

This testing build includes audit hardening for financial-year identity and duplicate repair, purchase-year mapping, recurring-investment date mapping, Portfolio Refresh, family scoping, report/import pagination, backup restore verification, Zakat cycles, and the expanded Demo profile.

Testing notes:

- Installer: `WAZO-Setup-1.1.8.exe`
- SHA-256: `3D5C803A6DB914418EA364AD39C8A9F5DE0642FCEC08B3FF54C9BC8E8E133CE8`
- Size: 103,207,734 bytes (98.4 MiB)
- Installer fix: the prior candidate could install without `WAZO.exe`/`resources/app.asar`, causing Windows to show a Browse-for-an-executable prompt. This testing candidate includes both payloads, resolves the Start Menu shortcut to `WAZO.exe`, and passed isolated installed-startup verification.
- Startup fix: incomplete/demo workspaces no longer run financial-year repair or attempt protected saves before initial setup and current-policy acknowledgement.
- The installer is not code-signed.
- This is a testing build, not the stable public release.
- Keep a verified WAZO backup before testing and report any issue through the support form.
