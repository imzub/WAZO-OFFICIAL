# WAZO v2.0.1.0 stable-line update

WAZO v2.0.0 remains the stable baseline release. WAZO v2.0.1 is a stable-line
bug-fix and enhancement update for v2.0.0; it does not create a new major
stable baseline. The v2.0.0 installer remains available in its original
versioned folder and is not deleted or overwritten.

This update includes the latest v2.0.1 fixes for recurring
investment ownership isolation, historical Financial Year reconciliation,
large-workspace import staging, searchable investment targets, responsive
Financial Life navigation, and repeat-safe Portfolio refresh behavior. It also
hardens the release verifier for pnpm dependency layouts and standardizes
spacing between labeled toggle controls across the application, including
Zakatable and Privacy controls.
