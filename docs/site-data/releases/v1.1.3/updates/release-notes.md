# WAZO 1.1.3

Status: product update complete; public installer packaging pending.

## Highlights

- Guided first-run setup for profile, members, country, currency, regional
  format, financial year, and optional zakat.
- Reusable Asset Library definitions and allocation targets.
- Unified Assets workspace for holdings, SIP and recurring plans, pending
  reviews, and confirmed transactions.
- Review-first handling for backdated recurring installments before holdings
  and cost basis change.
- Asset Performance and Reports with category mix, gain or loss, CAGR, and XIRR.
- Fresh PDF, print, Excel, CSV, and JSON outputs.
- Import preview and confirmation, protected pre-restore and pre-reset backups,
  and stronger last-known-good recovery.
- Manual and scheduled local backups with missed-run detection.
- Structural privacy across screens, previews, accessibility content, print,
  and exports.
- Optional online rate updates with network protections.

Existing profiles, members, settings, assets, and optional zakat preferences are
designed to migrate without data re-entry.

The installer must not be linked until packaging is confirmed ready.
