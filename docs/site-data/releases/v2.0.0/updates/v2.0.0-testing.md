# WAZO v2.0.0.0 testing installer

WAZO v2.0.0.0 is an optional Windows x64 testing candidate. WAZO v1.1.7
remains the stable public release.

This refreshed installer is sourced from private WAZO `Dev/QA` commit
`e864d7b`. The source audit includes a categorized 309-record defect and
regression ledger with 0 open automated-baseline defects. Current source and
package evidence includes 1,656/1,656 combined tests, 100,000 deep-audit
probes / 460,000 assertions, 68/68 bounded UI Humanity cases, 21/21 runtime

This candidate includes the v2 Financial Life, budgeting, income and CTC,
tax-workpaper, liabilities, Zakat, Overall Performance, calculators, editable
payment methods, policy packs, import/export, recovery, and backup/restore
workflows. It also retains the existing-user migration repair lineage from
source commit `4284642`: legacy append-only investment facts are preserved
across normalization and migration saves, while derived financial-year fields
may be repaired safely. It is intended for controlled testing and user feedback, not
as a stable release or professional legal, tax, Zakat, or financial-advice
service.

Before installing, back up your WAZO data. The installer is not code-signed,
so Windows SmartScreen or the browser may show an unknown-publisher warning.
Use the download only from the official WAZO website and verify the SHA-256
hash before running it.
